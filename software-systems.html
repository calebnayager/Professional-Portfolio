FleetPro Logistics Management System

Status: In Progress

Project Overview

A Business Analysis and Systems Development project focused on designing a digital solution for vehicle maintenance management within a growing logistics fleet.

The system is being developed from the business requirements and process analysis completed during the Business Analysis phase of the project.

Technologies & Tools

  • HTML5
  • CSS3
  • JavaScript
  • Python
  • MySQL
  • Git & GitHub
  • Visual Studio Code
  • Draw.io

Planned System Functionality

  • Vehicle and fleet management
  • Vehicle maintenance records
  • Maintenance scheduling and tracking
  • Fault and maintenance issue recording
  • Maintenance history
  • Service and repair information
  • Centralised maintenance information
  • Reporting and management visibility

Status: Completed

A Java desktop application developed to demonstrate object-oriented programming and the development of a functional vehicle rental management system.

The application allows vehicles and rental transactions to be managed through a graphical user interface.

Technologies & Tools

  • Java Swing
  • Object-Oriented Programming
  • Windows Batch
  • Windows Executable
  • jGRASP

Features

  • Add and manage vehicles
  • View vehicle information

  • Track active and completed rentals

Food Delivery System

Status: Completed

Project Overview

A Java desktop application developed to demonstrate object-oriented programming and the development of a simple food ordering system.

The application allows users to browse food items, build an order, and view the calculated order total through a graphical user interface.

Technologies & Tools

  • Java
  • Java Swing
  • Object-Oriented Programming
  • Windows Batch
  • Windows Executable
  • jGRASP

Features

  • Browse food items
  • Add items to an order
  • Remove items from an order
  • Calculate the order total
  • View an order summary
